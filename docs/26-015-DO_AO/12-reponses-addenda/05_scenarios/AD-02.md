# Scénarios — AD-02 Seuil par code d'absence

> Conventions : voir [../05_scenarios.md](../05_scenarios.md).

**Fichier** : `04-absences.feature`, scénario « Le seuil du code décide du remplacement long terme, sauf pendant une
période horaire en cours ».

| Étape | Ce qui est posé | Attendu | Pourquoi l'attendu prouve |
|---|---|---|---|
| 1 | Code `MALS` de catégorie **ponctuelle** avec `seuilJoursLongTerme: 14` | 201 | L'attribut est déclaré au descripteur ; un attribut inconnu serait refusé |
| 2 | Le même avec un seuil de 0 | 422 | Bornes 1 à 365 |
| 3 | Marc absent 20 jours (`MALS`) sur une période à venir | place `REMPLACEMENT_LONG_TERME`, `remplacementPossible: true` | Catégorie ponctuelle : sans le seuil, la place aurait été offerte |
| 4 | Julie absente 3 jours, même code | aucun `REMPLACEMENT_LONG_TERME`, `remplacementPossible: false` | Sous le seuil : gestion régulière |
| 5 | Période publiée qui commence aujourd'hui ; Marc absent 30 jours dès demain | place présente, aucun `REMPLACEMENT_LONG_TERME` | « à part si la période horaire est en cours » |

**Essais Java** : `AbsencesEffectifsDomaineTest.seuilLongTerme` (le seuil l'emporte sur la catégorie dans les deux sens ;
sans seuil, la catégorie), `.periodeEnCours` (publiée, commencée, non finie), `.comblement` (période en cours → attribuer
ou offrir, jamais réserver).
